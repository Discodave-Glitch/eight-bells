# Eight Bells V2 notes (for the maintainer)

- Engine hook: `compute(t)` takes its base row from `baseRow(t)`. `t.eng` is `euclid`, `cell`, `num`, `world`, `frac`, `mirror` or `wtd` (each has a `...Row(k,P,es)` function and finishes with `adjustTo`, so hit counts are exact); `t.es` is the per-track engine seed. Drift (`phase`) is applied in `buildTrack`: melody tracks get a shorter length, hat and perc lanes get a shorter cycle (`P`). Drums keep one shared length, so the loop length is always the drums' length.
- V1 codes are unchanged: the engine only adds random draws when it is not Euclid, so Euclid patterns for a given seed are identical to V1 (checked against the V1 build).
- Share code: `EB1:genre:bars:fw:seed:bpm:swing[:engine]`. Exact codes (`EB2`) are unchanged and load as Euclid tracks.
- Auto song: `lockedParts()` before each change and `applyLocks()` after, on every route (random, other genre, saved seed, go back). Locked tracks are kept as they are, unlocked tracks are rewritten in the locked tracks' key, scale and chords, and a snapshot's old lock flags are cleared.
- Release workflow: builds on both systems with `--publish never`, uploads the files as artifacts, and one job makes the release from whatever was built. Not run yet: untested until the first V2 tag. File names: `Eight-Bells-2.0.0-portable.exe`, `Eight-Bells-Setup-2.0.0.exe`, `Eight-Bells-2.0.0-x64.dmg`, `Eight-Bells-2.0.0-arm64.dmg`.
- The "V2 test" label next to the title is in `build/body.html` (class `ver`). Change it to "V2" for the release.
- Genres: 187 in ten groups. Groups no longer need to be a multiple of 6; the tiles simply wrap. The last 61 were added with `build/mk_genres.py` (data in `genres_new.txt`), each with an entry in AUTOG (instruments), AUTOK (drum kit) and SOUNDS (FM-1 sound tips).
- Song builder: `SONG` state, steps stored in localStorage `eb_song`. Each step restores the snapshot taken at song start, then runs the same function as the section button (`SONG_FN`). `songStep()` runs beside `autoStep()` in `tick`; `stopPlay` ends the song and restores the start pattern. Auto song and the song builder switch each other off.
- Engines: 20 (`ROWFN` maps engine ids to row functions). Non-Euclid engines set `t.mel`; `fillNotes` then picks scale steps from `engSeq(t.mel,t.es)` through `melDeg`, and `generate` uses `engProg` for the chords. Euclid is untouched so V1 patterns still match.
- Remembering state: localStorage `eb_last` (snapshot, saved every 2 s and on page hide) and `eb_ui` (open panels). The desktop window bounds are in `window.json` in the app's data folder (`app/main.js`).
- V3 preview sounds: `KITS`, `PATCHES`, `NAME_PATCH` (FM-1 sound-name tips mapped to patches), `PV` state in localStorage `eb_prev`, user samples in IndexedDB `eb_samples`. All of it lives in the preview branch of `schedule()` (the `preview` flag is true only when no MIDI output is connected), so the MIDI path is untouched; `chk/v3.js` compares MIDI bytes against V2 with an output attached.
- Sample track: `VOX` state in localStorage `eb_vox`, formant-synth vocals in `VOXP`/`voxVoice`, played by `voxPlay` from `schedule()` (only in preview, or when the user ticks the play-over option). It never touches `stepEvents`, so MIDI output is unchanged (`chk/vox.js`).
- Instruments: `SUBC` and `PARTC` configs feed `pxSubtractive` and `pxPartials`; `mkKit` builds the simple kits.
- Sample track v2: `VOXP` has 127 entries (grouped); words are phoneme strings in `WORDS` rendered by `voxWord` (vowels `VW`, glides `VG`, consonant noise `VC`). `VOICES` sets pitch offset and formant scale; `VOX.pitch`, `VOX.mode` (chord/fixed/up/down/walk) and `VOX.human` shape each note. Still preview-only.
- Sample track v3: `VOX.lanes` (up to 4 lanes, each snd/voice/k/r/pitch/mode/level/hold/custom), saved in `eb_vox` and inside `snapshot()` as `vox` (restored by `voxApplySnap`). Hold 0 = until the next hit. `voxSeg` uses a PeriodicWave glottal source, slow pitch drift, delayed vibrato, aspiration noise and five formants. `VOXP` has 204 entries. Instruments: `SUBC2`/`PARTC2` add 56 more (142 in all).
- Round 3: voice reverb bus (`voxBus`, convolver IR generated at runtime), legato via `LEG` WeakMap and `opt.from`, hold default 0 (migration `VOX.v`), master limiter (`OUTTAP`), `REC` ScriptProcessor recorder + `wavEncode`, `sliceSample`, `SYNC.ms` added in `tsOf` (default 0, so MIDI timestamps are unchanged), performance view (`body.perf`).
- Round 4: `AUTOP` genre-family rules + hashed `AUTOPOOL` fallback in `autoPatch`; `SURP` (localStorage `eb_surp`) with `surpriseSounds()` / `surpriseEngine()` hooked into the genre click handlers; Surprise buttons in the Engine and Preview panels. Perf button fixed (own row, fixed top-right when active). Voices: `sing` mode default (stepwise), `voxWarm()` pre-builds reverb and wave.
- Round 5: local punch effects (`fxBuild` chain inserted between `master` and the compressor in `ensureAudio`, `fxLocalStart/Stop`, 4 s ring capture via ScriptProcessor while playing for the loop family); `fxLocalMode()` = preview mode. Performance view collapses all `details` and restores them afterwards (no longer hides). `sfx()` wrapper keeps playback alive if a sound throws.
- Round 6: `TCOL` (localStorage `eb_tcol`) per-track collapse via `.track.col`; `#autobox` and `#secbox` details; `#tcolall`.

- Instruments: 193 in PATCH_LIST (51 added from SUBC3 and PARTC3 recipes). Voices: 14 voice types, 421 sounds including Numbers, Letters (A to Z), More words and Phrases. New voice/word code goes before `VOX_GROUPS` is computed; spoken forms for device speech go in `SPEAK`.
- Per-track Level (true bus gain, 0 is silent), Pan and a level meter are browser-preview buses (`busFor`); they never change the MIDI sent to the FM-1. Clear buttons empty a track, lane or drum set. Deleting a saved pattern, seed or the song uses the two-step `sure()` button.
- Section memory: `SECMEM` (one snapshot per section), `SECBASE` (the pattern before the first section was picked), `goSection()`. Cleared by `generate()` and `loadExact()` unless `SECKEEP`. Song codes are `EB3:steps:r|p:BASE~id.EB2code~...`.
